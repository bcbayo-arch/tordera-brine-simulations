# Tordera brine plume — numerical simulations

Static site presenting the MITgcm simulations of the brine discharge from the
Tordera desalination plant (ICM-CSIC, SALADET project).

**Live page:** https://bcbayo-arch.github.io/tordera-brine-simulations/

## What is here

Two model configurations, each run as **twin experiments** (identical runs with
and without the discharge, so the difference is exactly the plume):

- **Realistic nested model** of the outfall area — ~75 m horizontal resolution,
  107 vertical levels, real bathymetry, boundary conditions from the regional
  CATSEA model and hourly ERA5 wind. Four two-week windows of 2022 (two in April,
  two in July), each with a 7-day discharge.
- **Idealised slope model** — a straight shelf slope that isolates the effect of
  the wind, run under a modal (1 m s⁻¹) and an extreme (4.8 m s⁻¹) regime.

Brine: S = 60 psu, 24.4 hm³ yr⁻¹, diffuser at 21.5 m (nest) / ~19.8 m (slope).
The brine enters at the temperature of the receiving water, so the anomaly shown
is purely haline.

## Contents

`index.html` (the page), `media/` (animations and figures), `posters/` (video
thumbnails). Every animation is generated by an archived script from the model
output and is reproducible; checksums are kept with the source archive at
ICM-CSIC.
